Model Performance

The table below shows the actual test-set evaluation metrics for the Balanced Logistic Regression model used in this system.

83.55% Accuracy
24.30% Precision
75.36% Recall
36.75% F1-Score

Why is Recall important here?

In this imbalanced diabetes dataset the positive class (diabetic patients) is significantly underrepresented. Recall measures how many actual diabetic cases the model correctly identifies. A high recall (75.36%) means the model catches most true diabetic patients, which is critical in a medical screening context — missing a diabetic case (false negative) can have far more serious consequences than a false alarm (false positive).
